# 项目总览

## 1. 项目名称

面向网页操作的低算力 GUI Grounding + Web Agent 实践项目

## 2. 项目背景

近两年多模态智能体研究里，一个非常明确的方向是让模型不仅“看懂界面”，还要“基于界面执行动作”。相比具身机器人、3D 仿真和通用智能体，`GUI Agent` 具备更低的工程门槛和更清晰的实验闭环，非常适合作为研究生的入门型实践项目。

这一方向通常可以拆成两个相互衔接的问题：

1. `GUI Grounding`
   - 给定截图和文本指令，定位目标控件或可交互区域
2. `Web Agent`
   - 给定任务目标、网页观察和历史动作，预测下一步操作

本项目采用“先 grounding，后 agent”的路线，优先实现一个算力要求低、可以逐步扩展的系统。

## 3. 项目目标

### 3.1 总目标

实现一个能够在网页界面中根据自然语言任务进行观察、定位和动作决策的小型 Web Agent，并完成标准化实验评测。

### 3.2 子目标

- 完成 GUI grounding 最小模型或最小推理闭环
- 支持基础网页动作：
  - `CLICK`
  - `TYPE`
  - `SCROLL`
  - `SELECT`
- 支持最小的任务执行循环：
  - 观察页面
  - 预测动作
  - 执行动作
  - 读取新观察
- 在标准 benchmark 或可复现任务集上评估结果
- 完成错误分析和轻量改进

## 4. 项目范围

### 4.1 本项目包含

- 基于截图的 GUI grounding
- 面向网页的单智能体操作
- 简单记忆机制与历史动作建模
- 轻量模型推理或 LoRA 级别微调
- 离线评测和小规模在线执行

### 4.2 本项目暂不包含

- 桌面 OS 全系统操作
- 手机端跨 App 长程任务
- 多智能体协作
- 大规模多卡训练
- 真机机器人控制
- 复杂世界模型或强化学习训练

## 5. 推荐技术路线

项目按照如下路线推进：

### 阶段 A：Grounding 能力建立

输入：
- 页面截图
- 文本查询，如“搜索框”“登录按钮”“价格筛选”

输出：
- 目标点坐标 `[x, y]`
  或
- 目标框 `[x1, y1, x2, y2]`

目标：
- 先把“能找准按钮”这件事做稳

### 阶段 B：单步 Web Action 预测

输入：
- 当前页面截图
- 简短任务指令
- 历史动作摘要

输出：
- 下一步动作：
  - `CLICK(x, y)`
  - `TYPE(text, x, y)`
  - `SCROLL(direction)`

目标：
- 完成短程操作，如点击、输入、提交

### 阶段 C：任务级 Agent 闭环

增加：
- 环境执行器
- 多步循环
- 成功判定

目标：
- 完成一类简化 Web 任务

### 阶段 D：轻量研究改进

可选改进方向：
- 历史动作压缩
- 错误恢复机制
- DOM 文本与截图融合
- 候选点击区域排序
- 指令重写与子任务拆解

## 6. 为什么这条路线适合研究生入手

### 6.1 算力要求低

- 最小版本可直接基于 API 或开源小模型推理
- grounding 部分可单独训练，不必一开始就训练完整 agent
- LoRA 微调即可支撑阶段性实验

### 6.2 工程边界清晰

系统边界明确：
- 观察
- 定位
- 动作预测
- 执行
- 评测

### 6.3 容易形成研究叙事

可以自然形成论文式结构：
- 问题定义
- baseline
- 方法改进
- 实验
- 错误分析

## 7. 推荐资源配置

### 最低配置

- 1 台普通开发机
- 浏览器自动化环境
- 可调用多模态 API 或 7B 以下开源模型

### 推荐配置

- 单卡 GPU，显存 16GB 至 24GB
- 用于：
  - 2B 级模型推理
  - 小规模 LoRA 微调
  - grounding 模块实验

## 8. 建议 benchmark 路径

按“从易到难”推进：

1. `ScreenSpot` 或同类 grounding 数据
   - 验证界面元素定位能力
2. `MiniWoB++`
   - 验证网页短任务操作能力
3. `Mind2Web` 或其多模态版本
   - 验证真实网页任务泛化能力

## 9. 项目成功标准

满足以下条件即可视为项目落地成功：

- 有可运行的最小系统
- 至少在一个 grounding 任务集上得到可复现实验结果
- 至少在一个 web benchmark 上完成 agent 评测
- 有对照 baseline
- 有错误类型总结
- 有明确后续扩展方向

## 10. 预期成果物

建议至少形成以下成果：

- 代码仓库
- 实验配置说明
- 数据处理脚本
- 结果记录表
- 项目报告或论文雏形

## 11. 后续可扩展方向

项目完成后，可以继续扩展到：

- 从 Web Agent 扩展到 Desktop Agent
- 从单步 grounding 扩展到长程 GUI navigation
- 从纯截图输入扩展到截图 + DOM 融合
- 从单智能体扩展到 planner-executor 双模块架构
- 从 benchmark 扩展到真实业务网页自动化任务
